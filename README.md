# Movie Finder

A React + TypeScript app for browsing movies and TV shows, powered by the TMDB API.

## Features

-  Trending movies & TV shows updated weekly
-  Search across the entire TMDB catalog
-  Rich detail pages — poster, backdrop, rating, genres, cast, and similar titles
-  Save favorites, persisted in localStorage
-  Dark cinematic theme
-  Fully responsive

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** for build tooling
- **Tailwind CSS v4**
- **React Router** for navigation
- **TMDB API** for movie/TV data
